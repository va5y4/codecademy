# Rock, Paper, Scissors

A JavaScript implementation of the classic Rock, Paper, Scissors game, built for Codecademy's Learn JavaScript course.

## Overview
The program allows a user to play a game against the computer. It takes the user's choice, randomly generates a computer choice, compares the two, and determines the winner.

## Concepts Applied
* Arrow Functions & Parameters
* Conditional Statements (`if/else`)
* `Math.random()` & `Math.floor()`
* User Input Normalization (`.toLowerCase()`)

## How to Run
Run the file using Node.js in your terminal:
`node rockPaperScissors.js`
